# 🎄 AdventJS Solutions

My solutions to the [AdventJS](https://adventjs.dev/) coding challenges created by [@midudev](https://github.com/midudev).

## 📝 About AdventJS

AdventJS is a series of JavaScript, TypeScript, and Python coding challenges released daily from December 1st to December 25th. Each challenge presents a Christmas-themed algorithmic problem designed to improve programming skills and problem-solving abilities.

## 🗂️ Repository Structure

```
📁 adventjs/
├── 📄 README.md          # This file
├── 📄 WARP.md           # Warp AI development guide
└── 📄 reto-X.js         # Challenge solutions (X = challenge number)
```

## 🚀 How to Run

Each challenge is a standalone JavaScript file that can be executed with Node.js:

```bash
# Run a specific challenge
node reto-1.js
node reto-2.js
# ... and so on
```
